# 子宫性闭经会导致不孕，想要好孕有四种治疗方法

> 更新时间：2026-09-11 (UTC+8)

闭经是一种危害健康的妇科疾病，很多女性朋友都会出现闭经，但是很多女性都认为这个病不严重。其实它的危害非常大，闭经会导致女性朋友们出现不孕等状况。导致闭经的四个原因：子宫性闭经、卵巢性闭经、垂体性闭经、下丘脑性闭经，接下就说说什么是子宫性闭经？

子宫性闭经的病因

**子宫性闭经的病因**

1、环境变迁、精神创伤、过度劳累、体重骤增骤减、慢性消耗性疾病及手术、有产后或流产后失血史、感染史、休克史、用过避孕药等导致子宫性闭经。

2、4种疾病会引起子宫性闭经

（1.）子宫内膜损伤或粘连综合征一般发生在人工流产后、产后出血或流产后出血刮宫以后，多是由于刮宫过度，损伤了子宫，造成宫腔粘连，出现子宫性闭经。

（2.）子宫内膜炎是最常见的导致闭经的原因，子宫内膜炎是结核性子宫内膜炎，其他流产后或产后严重的子宫内膜炎也可发生子宫性闭经。

过度劳累引起的子宫性闭经

（3.）子宫发育不全或缺如由于副中肾管发育不全或不发育而致子宫发育不全或不发育，往往表现为原发性闭经。

（4.）子宫切除后或子宫腔内放射治疗后因生殖道疾病切除子宫后或因某些子宫恶性肿瘤经腔内放射治疗破坏子宫内膜后而出现子宫性闭经。

**子宫性闭经4种治疗方法**

**1、一般支持疗法**

包括精神安慰，解除顾虑，改善营养，劳逸结合，适当锻炼，以增强体质;如发现全身性疾病，要首先治疗;哺乳期超过1年者，应停止哺乳。

**2、对引起闭经的器质性病变进行治疗**

子宫内粘连可以扩大子宫腔，分离粘连，放置子宫内装置，防止再粘连，并使用雌激素，孕激素促进子宫内膜增生和脱皮。

对于卵巢或垂体肿瘤，门静脉或阴道闭锁，经诊断后可进行手术。对于生殖器结核病患者，给予抗结核治疗。

**3、孕激素替代疗法**

先天性卵巢发育不良或卵巢功能受到抑制或破坏，故失败，可用外源性卵巢激素替代治疗。这些患者由于缺乏正常卵泡和卵母细胞，不分泌性激素，如雌激素或雌激素，孕激素人工循环治疗，可以纠正生理和心理状态下雌激素的缺乏，促进生殖器官和继发性特征在一定程度上发展，改善性生活，并可导致月经周期性复苏出血。

**4、诱导排卵**

对于那些需要生育能力的人，卵巢功能不会丢失的激素或类似药物的患者可用于诱导排卵。

(1)垂体功能不全，可用于绝经后女性，提取促卵泡激素，促进卵泡发育，分泌雌激素，并结合绒毛膜促性腺激素治疗，排卵成功率高。

(2)垂体和卵巢功能正常，下丘脑功能障碍或非协调者，可用于纠正下丘脑垂体 - 卵巢轴排卵功能的诱导排卵。

(3)甲状腺机能不全，使黄体激素释放激素分泌，可用于减少促黄体激素释放激素(LH，RH)诱导的排卵量。

如果出现闭经情况，首先要到正规的医院进行详细的检查，最好做一个性激素六项检查。性激素六项检查的意义很重大的，不仅能够了解到隐藏疾病，而且还能观察疾病的发展和变化，对于有无炎症、有无活动性病变等多种疾病的诊断和治疗都具有一定的参考价值。女性患上闭经在饮食方面需要多加注意，不要吃辛辣带有刺激性的食物，养成良好的饮食习惯和生活习惯，远离闭经的困扰。
